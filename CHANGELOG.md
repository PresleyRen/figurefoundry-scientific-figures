# Changelog

## 1.1.0 — 2026-10-20

Re-audited all 16 selected Skills and connected their useful features to an
executable, searchable figure-production workflow.

- Added a feature-by-feature source registry: 103 source features, 41 capability
  entries and 26 bilingual specialty routes, each with implementation, references,
  complementary capabilities, tests and an extension target.
- Added wide-table curves, independent-unit point overlays, OLS equation/R²,
  explicit normal/lognormal density fits, five matrix normalizations, asymmetric
  GridSpec layouts and role-specific typography.
- Added five named themes and shared project defaults. Category colors, markers
  and line styles retain their meaning when figure order or category order changes.
- Bundled runnable Seaborn FacetGrid, PairGrid, JointGrid and clustermap recipes,
  with full-data provenance and the same native SVG export checks.
- Added figure-set contracts, candidate selection, scientific entity/quantity
  records, captions, alt text, selected-source handover and persistent upstream
  source freezing.
- Added local paper-HTML figure intake, literature-benchmark provenance checks,
  Python/Notebook source navigation, palette luminance/contrast reports, SVG
  accessibility metadata and controlled edit comparison.
- Fixed composition checks so a new panel letter or another panel's text cannot
  conceal an outlined source chart or missing source labels.
- Added actual 2D/3D comparison evidence, behavioral conflict cases, portable-Skill
  execution, four recipe previews and an independent two-figure project trial.
- Rewrote the Chinese README with a complete capability overview, all 16 sources,
  a text-maintained Mermaid structure map and symptom-to-module extension guide.

Exact test counts, rendered artifacts and execution environments are recorded in
[TEST_REPORT.md](docs/TEST_REPORT.md). Source features retain their explicit
native, recipe, workflow or external-adapter integration mode.

## 1.0.0 — 2026-10-20

Initial FigureFoundry release. Unified 16 selected scientific-figure skill entries
into an independently implemented, documented workflow with source/license audit.

- Native 16-kind data plot engine, explicit independent-unit uncertainty and source hashes.
- Live-text SVG master, exact physical dimensions, PDF/PNG companions and manifest.
- Native scientific diagrams, feedback topology and ID-safe SVG composition.
- Read-only structural/font/label SVG audit with meaningful failing counterexamples.
- Journal profile workflow, complete capability registry and extension map.
- Chinese README, source attribution, CF-01–16 conflict decisions, behavioral tests,
  reproducible examples and independent end-to-end usage evidence.

Known boundaries: no journal acceptance certification; no generic paired or
hierarchical statistical model; no raster scientific-image-to-vector conversion;
optional R/TikZ/Plotly/Draw.io pipelines require separate runtime validation.
