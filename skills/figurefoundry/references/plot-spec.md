# Plot specification and custom-source API

Run `python <skill-dir>/scripts/figurefoundry.py plot --spec figure.json --out figures/result`.
The output argument is a basename; `.svg/.pdf/.png` is also accepted and normalized.
Existing outputs are protected unless `--overwrite` is explicitly selected.

## Minimal reproducible example

`observations.csv`:

```csv
method,seed,accuracy
Baseline,1,0.71
Baseline,2,0.73
Baseline,3,0.72
Proposed,1,0.76
Proposed,2,0.75
Proposed,3,0.77
```

`figure.json`, beside that CSV:

```json
{
  "version": 1,
  "claim": "Compare independently repeated runs; values are illustrative.",
  "data_status": "synthetic",
  "title": "Synthetic example",
  "figure": {"width_mm": 90, "height_mm": 70, "font_pt": 8, "min_font_pt": 6},
  "panels": [{
    "kind": "bar", "data": "observations.csv",
    "x": "method", "y": "accuracy", "unit": "seed",
    "estimator": "mean", "error": "ci95",
    "xlabel": "Method", "ylabel": "Accuracy (fraction)"
  }]
}
```

This is a mean and two-sided Student-t 95% confidence interval across the named
units. It is not a paired comparison test. A model claim needs the appropriate
study design, metrics and statistical analysis outside this generic renderer.

## Figure-wide fields

| Field | Meaning/default |
|---|---|
| `version` | `1` |
| `claim` | Intended scientific message, saved in the manifest |
| `data_status` | `user-supplied` or `synthetic`; synthetic requires visible "Synthetic" in title |
| `title` | Optional figure-wide title |
| `figure.width_mm`, `height_mm` | Exact page dimensions; default 180×110 |
| `figure.rows`, `cols` | Panel grid; default one row with all panels |
| `figure.font_pt`, `min_font_pt` | Base text and actual SVG audit threshold; defaults 8 and 6 |
| `figure.font_family` | Installed family; default DejaVu Sans; configure an available CJK font for Chinese |
| `figure.preview_dpi` | PNG preview only; default 300; SVG geometry has no fixed DPI |
| `palette` | Semantic label→color mapping, reused for all panels |
| `formats` | Always include `svg`; default `["svg","pdf","png"]` |
| `journal` | User-verified journal profile attached to provenance; not automatic certification |
| `panels` | One or more panel objects; maximum 26 |

Panel `data` paths are relative to the spec. `sheet` chooses an XLSX sheet index or
name (default first sheet). Shared labels/colors require shared explicit settings
when figures are generated by separate commands. Never assume observed category
order is identical in independent datasets.

## Common panel fields

`id`, `title`, `xlabel`, `ylabel`, `xlim`, `ylim`, `xscale`, `yscale`, `legend`,
`legend_loc`, `legend_cols`, `x_tick_rotation`, `spines="all"`, `seed`.

Explicit axis limits are logged because they may crop observations. Limits must
increase and be finite; log axes require strictly positive data in the displayed
domain. Review a log transform scientifically, and never use log bars. Plain text
including Unicode symbols is preserved as SVG text; automatic LaTeX/math parsing
is disabled. For a complex mathematical expression, provide a separate editable
text annotation/source and audit it rather than silently converting glyphs to paths.

## Native graph kinds

| `kind` | Required fields | Options and limitations |
|---|---|---|
| `line` | `x`, `y` | `hue`, `order`, `hue_order`, `x_type="categorical"`; raw single values or explicit aggregate; missing y produces gaps |
| `bar` | `x`, `y`, `estimator` | `hue`, ordering; uncertainty needs `unit`; numeric axis includes zero |
| `scatter` | `x`, `y` | `hue`, `point_size`; `fit="ols"` explicitly adds an OLS fit and manifest coefficients |
| `box` | `x`, `y` | `order`, `raw_points=true`; 1.5-IQR whiskers, all observations retained in raw overlay |
| `violin` | `x`, `y` | `order`, `raw_points=true`, `bandwidth="scott"`; singleton/constant density replaced by a disclosed value line |
| `hist` | `x` | `hue`, `bins` (auto/int/edges), `density`; all groups share the same bin edges |
| `ecdf` | `x` | `hue`; all complete observations, tied values counted, no smoothing |
| `heatmap` | `x`, `y`, `value` | Long-form rows; `x_order`, `y_order`, `cmap`, `vmin`, `vmax`, `annotate`, `number_format`, `annotation_font_pt`; duplicates need `aggregate="mean"/"median"` |
| `confusion` | `truth`, `prediction` | Raw labels; `labels` order; `normalize="none"/"row"`; manifest includes original counts |
| `correlation` | `columns` | Explicit numeric column list; `method="pearson"/"spearman"`; listwise complete-case policy recorded |
| `roc` | `truth`, `score` | Binary labels; `positive_label=1`, `hue`, `show_metric`; threshold ties handled exactly; AUC recorded |
| `pr` | `truth`, `score` | Binary labels; `positive_label=1`, `hue`; AP is the stepwise average precision, not trapezoid PR area |
| `forest` | `label`, `effect`, `lower`, `upper` | Provided intervals, `interval_definition`, `reference`; no fabricated replication or refitted effect |
| `pareto` | `x`, `y` | `minimize_x=true`, `minimize_y=false`, optional `label`; `connect_frontier` is an explicitly disclosed visual guide |
| `stacked_bar` | `x`, `y`, `hue` | One nonnegative value per x/component; no missing components; `normalize=true` for row fractions |
| `volcano` | `x`, `p` | x is supplied effect/log fold change; p column contains supplied p/q in (0,1]; explicit thresholds and `p_definition`; all-null results are valid |

The CLI is deliberately strict about ambiguous aggregation. For complex nested
grouping, hierarchical inference, survival models, calibrated evaluation or other
specialties, write a domain-correct analysis/source script and use the shared
exporter. The wider skill can plan and author these graphs; they are not all
implemented as native one-command chart types. See `optional-backends.md`.

## Statistics fields

| Field | Meaning |
|---|---|
| `estimator` | `mean` or `median`; bar requires it explicitly |
| `error` | `none` (default), `sd`, `sem`, `ci95`, `bootstrap95` |
| `unit` | Explicit independent unit column; required for any uncertainty |
| `within_unit` | `mean` or `median`; required when a unit repeats inside the same group; justify the reduction |
| `bootstrap_draws` | Default 2000, minimum 200, resamples named unit summaries |
| `seed` | Default 1729, recorded for bootstrap/jitter reproducibility |

SD uses n−1. SEM = SD/√n. CI95 is mean ± t(0.975,n−1)·SEM. Bootstrap95 is the
2.5th/97.5th percentile interval of resampled mean/median. Median + SEM/t CI is
rejected. n<2 does not receive fabricated zero uncertainty. Missing y is excluded
from an explicitly requested group estimate and counted in the manifest; raw line
missingness remains a gap. Neither method automatically accounts for clustering,
pairing, temporal dependence, multiplicity or selection bias.

## Custom Python/Seaborn figures

Put the skill scripts directory on `sys.path` or invoke from that directory:

```python
from ff_export import export_figure
# fig is an existing Matplotlib Figure built from the real analysis.
manifest = export_figure(
    fig, "figures/custom", width_mm=180, height_mm=110,
    min_font_pt=6, expected_labels=["Time (s)", "Signal (a.u.)"],
    provenance={"analysis": "analysis.py", "data_sha256": "record the real hash"}
)
```

Create labels with `text.usetex=False`; set `text.parse_math=False` if literal
editable labels are required. No artist or colorbar may be rasterized. For dense
heatmaps use vector cells, and explicitly disable colorbar rasterization. The
exporter refuses a failed master. Keep a complete required-label inventory and
visually inspect the result, especially for specialty artists and CJK fonts.
