# 数据、统计和科学含义

美化只改变表达方式。输入数据、比较范围、实验事实、阴性结果和已声明的不确定性不能为了视觉效果被改写。先用一句准确的问题或发现说明这张图的任务，再安排面板；这句话可以是“未观察到清楚差异”，无需预设阳性结论。

## 1. Figure Contract：作图前的最小约定

| 内容 | 需要明确的事实 |
|---|---|
| question / finding | 图回答什么；措辞与证据力度一致，区分相关、预测和因果 |
| source | 原始文件、数据表、分析脚本/输出及版本；真实、模拟、教学示例分别标记 |
| variables | 每列含义、单位、类别顺序、时间/空间坐标和参考系 |
| design | 生物/技术重复、受试者、批次、配对、随机化、种子/折数等适用信息 |
| estimator | 中心统计量、估计对象、误差/区间的含义和计算方法 |
| transformations | 排除、缺失、归一化、对数、分箱、平滑、拟合等已采用操作 |
| visual encoding | 每个位置、长度、面积、颜色、形状、连线表达什么 |
| deliverables | 图源、数据、配置、重建代码、审核记录、图注和期刊记录 |

既有分析输出可以直接画；没有要求重新分析时，不擅自重算差异检验或替换模型。缺少会改变结论的信息时，把未决项说清并继续其他可独立的工作，不能通过编造样本量、单位或统计值填满图。

## 2. 数据读取与变换

原始输入保留不改；绘图表和中间表另存。数据缺失、无穷值、字符串解析失败、检测限、真实零值和分析排除应分别记录。检查每个必要列的类型、维度、取值范围和单位；报告实际使用行数和被排除行数。

时间或有序观测中的缺失常有科学含义。折线应保留断口，不因删除 NaN 后重新连线而暗示连续观测。配对图按配对 ID 连线，不能仅用行号把不相干样本连接。热图中的缺失以独立颜色/标注显示，不能自动作为零。[Matplotlib 缺失值示例](https://matplotlib.org/stable/gallery/lines_bars_and_markers/masked_demo.html)

允许有科学理由的汇总，但需要保存方法：分箱边界、平滑窗口/带宽、聚合单位、归一化公式和参考组、排除规则、拟合模型和使用样本。不能只挑能提高差异或相关的点，也不能对某一组单独采用有利处理。显示数量减少时，保留原始表和全量统计，说明图面表示的改变。

表格化记录示例：

| 操作 | 合理记录 | 不接受的替代 |
|---|---|---|
| 按独立实验汇总 | 每个 experiment_id 内先汇总技术重复；n 为独立实验数 | 把每个技术测量点都计作新的独立实验 |
| 时序平滑 | 平滑算法、窗口、边界处理，保留原曲线和缺失区 | 只展示平滑结果且暗示全是原始观测 |
| 对数变换 | 变量、底数、零/负值策略和原因 | 为能画 log 轴随意加不披露的常数 |
| 异常值处理 | 分析前规则或有证据的质量失败、排除数及原始值 | 因为点破坏“漂亮趋势”而删除 |
| 文献图数字化 | 文献来源、图号、数字化工具、近似误差 | 将读图近似值描述为实验原始数据 |

## 3. SD、SEM 和 CI 不是同一种误差

每个包含区间的面板说明中心是 mean、median、模型估计或其他量，并说明区间代表什么。绘图函数可以显示误差，不能替实验设计决定哪个误差合适。[Seaborn 误差条解释](https://seaborn.pydata.org/tutorial/error_bars.html)

| 标记 | 含义与约束 |
|---|---|
| SD / 标准差 | 描述观测值的离散；样本 SD 通常使用 n−1 分母 |
| SEM / 均值标准误 | 独立同分布简化条件下为 SD/√n；并不描述原始数据分布宽度 |
| CI / 置信区间 | 对目标参数的区间估计；注明置信水平、计算方法、重复采样单位和假设 |
| IQR / 四分位距 | 分布中间一半的范围；不是均值的不确定性 |
| prediction interval / 预测区间 | 新观测的区间，与模型均值的 CI 不同 |
| provided interval / 已给区间 | 从可信上游分析输出读取端点，保留该分析方法的说明 |

只有一个独立重复时，样本 SD/SEM 无法用常规公式可靠计算。将其标记为不可估计或不绘误差，不把它伪装成“0 误差”。若误差已经给出，确认输入是端点还是非负误差长度；例如 estimate=4、CI=[3,6] 对应上下误差长度 [1,2]。[Matplotlib errorbar 参数](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.errorbar.html)

bootstrap 的随机种子保证重复运行能复现抽样，不会把有依赖的观测变成独立。受试者内多次测量应尊重受试者层级；配对变化应通过配对差值/相应模型推断，不能把两个时点各自 CI 当作变化量 CI。

## 4. 模型评估和重复实验

ML 图件记录指标定义、数据分割、基线、训练/评估条件、种子或折数以及不确定性的对象。五次训练种子的 SD 描述训练随机性对该评估设置的影响，不能自动解释成对新总体的泛化置信区间。交叉验证折之间可能共享训练数据，不能未经分析把每折当作完全独立样本。

若同一测试集有 1,000 条样本，五个训练种子产生五个性能分数，这两个 n 回答不同问题。标注“5 runs；每个 run 在固定 1,000 个测试样本上评估”比孤立写 n=5000 清楚。缺少定义时，保留分数点，不臆造区间或实验独立性。

分类阈值、ROC/PR、混淆矩阵的正类和归一化方向应写清。不同方法的比较应使用同一评价口径；不能从不同数据分割中挑各方法的最好结果，再呈现为公平并列实验。

## 5. 合法阴性结果必须能画

数值合法性检查可以拒绝缺列、维度错配、负误差长度或不适用的对数输入；**不能以 p 值不够小、热图不够鲜明、相关不够高、AUC 不够好、组间差太小为理由拒绝绘制或修改数据。**

回归输入应包含：相同组均值、负效应、宽区间跨过零、全非显著差异结果、低相关矩阵和接近随机的分类输出。它们是合法的研究结果。展示时保留原来的单位和范围，不通过改变色标、坐标截断或选择性放大制造差异。

显著性星号只能来自确切检验及其比较、校正和阈值。没有分析结果时不添加星号；精确 p 值与效应及区间通常比孤立星号更有信息。绘图 Skill 不保证任一统计检验适用于用户研究。

## 6. 合成示例与真实图像

测试和教程可以使用合成数据，但应在示例说明、配置/manifest 和适当的预览/图注中清楚标记。固定种子用于复现示例，不证明它是实验测量。交付时不能把示例图当成用户数据结果，也不能为补齐缺失面板生成似真的“实验数据”。

真实图像保留原文件、采集信息和已进行的图像处理。严格无位图的 SVG 流程适用于数据图和矢量示意；不会把显微图通过描边变成仍保留原始测量意义的矢量实验图。示意图清楚注明 schematic，比例未按真实尺寸时写 not to scale。

## 7. 视觉调整的边界

条形长度比较通常保留零基线；散点和折线可以按科学目的调整范围，但刻度和范围必须显式，不制造误导。用面积编码时按面积映射数值，不让半径线性变化导致面积夸大。比较热图共享单位和规范化；需要各自尺度时清楚标明。

颜色之外使用线型、标记、直接标签或分面表达组别。检查实际大小和灰度；一次灰度检查不能代表所有色觉条件。抖动只为缓解重叠，不改变数值轴上的数据位置；如使用横向分类抖动，保留其类别归属。

## 8. 无水印与可追溯性同时成立

程序输出不添加 AI 角标或工具品牌。数据来源、版本、重建命令和必要的工具使用说明保存在代码、manifest、图注或方法部分。图中研究内容本来包含 AI/ML 时照常保留；不能用关键词清除器删去科学术语。也不能把无水印描述为“没有使用 AI”或“无需满足投稿披露”。

来源核对、数值断言、SVG 结构审核和视觉观察各自记录。只写确实执行的检查；自动审核无法证明实验真实、推断正确或期刊必然接收。
