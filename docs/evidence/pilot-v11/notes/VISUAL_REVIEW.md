## 具体观察

图 1 的所有七个 epoch 标记、SD 误差条和阴影带均可见。修订后的横轴 padding 保留了 0 和 30 两端的完整圆、三角形和方形；没有用绘图区外的新数值扩展曲线。三条方法曲线均与图例的颜色、点形及线型对应。图例位于较低成功率的空白区域，不覆盖数据。标题 Synthetic、统计说明、轴单位和刻度没有缺字、互相覆盖或页面裁切。

图 2 的零基线柱形与右侧扩大范围的原始点使用各自明示的纵轴。左侧所有误差条清楚可见，右侧每方法六个点均与 seed ID 对齐；底部三列 marker 图例占用没有观测的空间，不遮挡任何数据点。两个面板标题、纵轴标签和总标题均有清楚间距。散点之间没有暗示时间连续性或配对的连线。

最终最小文字为 7.5 pt，轴标签为 8.5 pt，图例为 8 pt。放大审阅未发现缺失 glyph、文字描边替代或 marker 裁切；两张图的 Synthetic 标签始终可见。灰度中 Baseline 与 Proposed 明度接近，但圆形/方形及学习曲线虚线/实线有区别；图 2 的 marker 图例使该图可以独立阅读。此处仅记录实际灰度审阅，没有宣称进行了全面色觉模拟。

## 两套图 2 候选的比较

两版均在 180 mm 相同物理宽度下审阅。采用的是补齐独立图例后的 v2 科学内容，原值、统计、每组 n、坐标范围及编码完全相同。横排的实际比例见 [横排 v2](../qa/figure-2-horizontal-v2-96dpi.png)；竖排的实际比例、放大及灰度见 [竖排 v2](../qa/figure-2-stacked-v2-96dpi.png)、[竖排放大](../qa/figure-2-stacked-v2-300dpi.png)、[竖排灰度](../qa/figure-2-stacked-v2-grayscale-96dpi.png)。横排的最终精修仅改变文字与网格颜色，几何未改，其放大及灰度审阅对应前表中的正式版本。

| 判断项 | 横排 180 × 90 mm | 竖排 180 × 130 mm |
|---|---|---|
| 第一眼看到的信息 | 总标题后同时看到方法均值与单次运行 | 先读均值，再向下读单次运行 |
| 方法比较 | 两个证据视图并排，容易对应 | 上下切换，需更多视线移动 |
| 标签与图例 | 在当前字号下完整，图例未覆盖点 | 也完整，但空间明显宽裕 |
| 空间利用 | 六个 seed 在可辨范围内紧凑排列 | 三类别的宽柱及六个 seed 间隙占较多空白 |
| 选择理由 | 同时读取均值与运行离散，少用 40 mm 高度 | 可保留给版面允许纵向阅读的替代情况 |

选中横排，并将精修后的 SVG 登记为图 2 的活动源。竖排保留为命名候选，不将它描述为错误版式。

## 编辑试验的实际观察

在 [一次性编辑预览](../qa/editability-text-and-shape-96dpi.png) 中，标题确实变为 “Synthetic editable text test”，原生页面背景 path 的填色确实变为浅黄色；两面板的定量位置保持不变。此预览是可编辑性试验，未被选入正式图集。原 SVG 保持原哈希。

对同一试验，未给允许改字的 ID 时 `revision` 拒绝；给出具体 text ID 后通过。另一个负例只移动了一个散点坐标，结构审核仍通过，但 `revision` 正确返回不通过。因此没有把“仍是合法 SVG”混同为“定量内容未变”。
