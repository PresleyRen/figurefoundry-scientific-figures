# Figure set design (Synthetic)

All inputs are supplied synthetic demonstration data. This is a planning profile; no target journal, article type or submission stage was specified. Labels use English for a methods paper.

Figure 1 answers how mean task success changes across the seven observed training epochs. Mean and n−1 sample SD are calculated separately for each method and epoch across six seed IDs. Repeated epochs within a run are not counted as independent new runs. No smoothing, interpolation, normalization, exclusion, or significance testing is used.

Figure 2 answers both the final method comparison and the extent of individual run variation. Panel a shows mean ± sample SD with a zero baseline; panel b shows every endpoint once at its seed ID, with a clearly labeled expanded vertical scale. The same numerical seed labels across methods do not establish pairing, so no run-to-run or cross-method lines are drawn.

Two Figure 2 layout candidates use exactly the same panels, data, statistics, ranges, typography and semantic palette, at a common 180 mm width: horizontal 180 × 90 mm favors simultaneous reading with lower page cost; stacked 180 × 130 mm gives every panel more horizontal space and a top-to-bottom sequence. Selection follows actual rendered review.

Methods: Baseline = #666A73 / circle / dashed; Context = #D55E00 / triangle / dotted; Proposed = #0072B2 / square / solid. Line styles encode methods only where lines are scientifically meaningful. Raw endpoints use matching colored marker shapes. Bar colors use the same method mapping.
