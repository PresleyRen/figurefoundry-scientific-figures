# 冲突决策与验证合同

这份记录说明候选方案为何保留或替换，并为每个取舍定义可观察的验证标准。来源编号 S01–S16 对应 [SOURCES.md](SOURCES.md) 的固定提交。

**“已读源码”“机制对照通过”“本项目回归通过”“人工看过成图”是四种不同证据。** 不把上游 README 的自述、文件扩展名或一个漂亮的预览图计作完整测试。涉及审美和科学解释的决定也不能伪装成程序自动证明。

## 1. 选择原则

本项目按以下顺序解决冲突：实验数据与科学含义；用户明确的 SVG/文字编辑约定；当前适用的期刊要求；可重复生成和机械审核；最终尺寸下的可读性；装饰与个人风格。较低层的优化不能破坏较高层的要求。

源码比较已经完成；实际执行结果由发布测试记录填写。下表的“验证标准”描述需要怎样证明规则有效，不宣称尚未运行的用例已通过。

## 2. 规则与对照

| ID | 冲突与来源 | 保留方案及理由 | 验证标准 |
|---|---|---|---|
| CF-01 | SVG 字符轮廓 vs 文字节点；S01/S06 与 S12 的 --no-fonts 路径 | 默认 svg.fonttype=none，保留真实 text/tspan。路径仍用于线和图形；不能把“包含 path”误判成错误 | 同一带坐标标签的图用两种字体设置导出；严格路径须保留预期标签和非空文字节点。纯轮廓文字不能仅凭无 image 通过 |
| CF-02 | imshow/PNG 热图 vs 矢量网格；S02/S06/S07/S11 | 数值矩阵以非栅格化网格/矩形绘制，色条也必须是矢量 | 同一小矩阵分别导出，解析最终 SVG 的 image 节点；正确数值/范围一致。除热图主体，还测试默认色条可能触发的栅格化 |
| CF-03 | bbox_inches=tight vs 精确毫米尺寸；S01/S06/S13/S15 | 页面宽高先确定，默认不裁切画布；通过布局间距处理留白 | 带较长轴标签的图在相同 figsize 下分别导出；读根 width/height/viewBox 并换算毫米；预期误差在声明容差内，不只读取输入 figsize |
| CF-04 | Nature/Science/SCI 名称预设 vs 实际期刊文件；S01/S04/S07/S08/S13 | 预设只作起点；保存期刊、阶段、官方 URL、核查日期和未决项 | 配置缺失来源时必须显示 provisional/unverified。没有实查不能输出“完全合规”。Nature 89/183 与 90/180 mm 冲突应可被记录而不是静默覆盖 |
| CF-05 | 强制四边框 vs 去除上/右边框；S02/S07/S08 | 作为风格参数按图型选择，比较面板保持一致；热图边界与散点轴框可以不同 | 在同一数据上渲染两版，验证数据、轴范围、标签和统计值不变；最终尺寸人工检查。没有普遍“最好”的机械评分 |
| CF-06 | 装饰性三维、曲面位图/阴影 vs 二维定量比较；S11/S15/S16 | 定量比较优先公共坐标的二维位置；真实空间结构可由来源支持的几何示意表达 | 数值一致性及无 image/滤镜型效果检查；人工核查遮挡、比例、颜色编码和不确定性。不得为视觉冲击改数值 |
| CF-07 | 数据区域占位模板 vs 可提交实验面板；S09 与数据绘图路径 | 正式图的每个定量面板都来自数据/分析结果；占位模板只作注明示例的布局资产 | 用可识别测试标签组合两个真实 SVG；检查预期标签、图元及来源仍存在；占位面板没有来源时不得宣称完成实验图 |
| CF-08 | 必須达到显著数/相关强度/组间分离才能渲染；S11 Step 5.5 | 完全排除此门槛；只检查数据类型、定义域、维度和统计输入是否合理 | 零组间差、低相关、全非显著火山图、接近随机分类 ROC、负效应都应按原值绘制。输入输出摘要值相等；合法阴性结果不触发“修数据” |
| CF-09 | 自动 mean/CI vs 明确独立重复和误差；S03/S06/S08/S11 | 显式中心、SD/SEM/CI、n、重复单位；重复测量与技术重复不能伪装独立样本 | 用手算小样本核对 SD/SEM；样本不足时标记无法估计。验证有 subject/seed/run 语义的输入不会被描述成独立生物样本 |
| CF-10 | 无条件降采样/平滑 vs 完全禁止任何汇总；S02/S11 | 不静默删除；确需分箱、平滑、聚合时保存原始数据和方法、参数、计数，声明改变了哪种表示 | 确认默认不丢点；有缺失时间点保留断口；进行汇总时总计与样本数可追溯，处理前后 hash 和转换记录齐全 |
| CF-11 | 矢量扩展名即通过 vs 实际 SVG 内容检查；S13/S14 | 解析 XML、文本、图元、引用和物理尺寸；拒绝仅包装 PNG 的 SVG | 合法 SVG 通过；image 包装、畸形 XML、重复 ID、无效内部引用等明确失败。审核不能把解析成功称为科学正确 |
| CF-12 | R/Python 先 PNG 再拼接 vs 原生 SVG 合并；S11 | 独立面板从源数据导出 SVG，组合时保留图元、文字、裁剪及内部引用，避免 image 包装 | 组合含相同 ID 的两个 SVG，检查 ID 隔离与 url(#id)/href 更新；测试缩放后字号与面板边界，查看实际成图 |
| CF-13 | 没指定 Python/R 就停止；S06/S07/S15 | 已有项目沿用现有栈；新任务默认 Python，依据上下文选择常规图型并继续 | 指令审阅：普通 CSV 出图请求没有多余强制后端确认；确实缺少单位、配对关系或真实数据时只问影响结论的信息 |
| CF-14 | “可编辑”混用源代码、路径、文字和底层数据 | 分别报告：原始数据可改、源脚本可重建、SVG 图元可改、SVG 文字可改。严格式要求后二者同时满足 | 已知标签出现在 text/tspan；缩放后字号合格；人工用实际可用的查看/编辑工具检查。没有编辑器实测时不得声称跨所有编辑器兼容 |
| CF-15 | 无 AI 角标 vs 清除来源或伪称人工制作 | 原生绘图不增加角标/品牌水印；来源与工具使用记录另存，保留图内正确注释 | 默认输出没有添加平台角标。数据中真实的 AI/ML 字样不可因为关键词误删；审核不能用词汇黑名单代替图件来源判断 |
| CF-16 | 内置旧模板“支持” vs 可选专业后端未实跑 | 原生已实现、自动测试、人工复核、可选指导分别记录；R/TikZ/Plotly 不借用上游状态 | 缺依赖时给出准确诊断；能力表不把未执行后端写为 PASS。新增后端须通过同一 SVG 审核合同后才能提升状态 |

## 3. 可重复验证方式

机制对照仅需独立实现最小候选行为，无需安装或执行整个上游 Skill。例如，比较 Matplotlib 字体路径与文字节点，可以用相同数据、相同标题、相同环境，仅改变 svg.fonttype；比较矢量热图时也仅改变网格表示。这种测试验证的是相关技术冲突，不是对来源作者整套项目的质量排名。

每条已执行记录至少写入：

| 字段 | 内容 |
|---|---|
| conflict_id | CF 编号 |
| fixture | 输入数据或测试文件及其位置；示例数据明确注明 synthetic |
| environment | Python、绘图库、平台与所用可选工具的实际版本 |
| command | 本次运行的准确命令 |
| observation | 文字/位图数量、物理尺寸、数值断言、退出码或人工观察 |
| result | pass / fail / manual-reviewed / not-run，范围明确 |
| artifacts | A/B 文件、审核 JSON、截图/预览和日志的相对路径 |
| limitation | 不涵盖的图型、字体、编辑器、期刊或后端 |

自动结果以发布时随仓库保存的 [TEST_REPORT.md](TEST_REPORT.md) 为准。对照中失败的候选可以证明为何排除它；不能为了“全绿”删掉预期失败的反例。审美选择以参数和成图说明，科学真实性以来源和作者确认，期刊适用性以官方记录，各自保持证据边界。

## 4. 扩展时保持这些条件

新增图型先映射至 chart-selection.md 的科学问题，再给出最小真实/合成输入、无效输入和阴性结果输入。新增后端先通过 CF-01/02/03/11/12/14，再扩展样式。更新期刊预设先核查 CF-04。替换统计或数据处理模块先回归 CF-08/09/10。

功能可以增加；严格 SVG、可追溯数值以及合法阴性结果的可绘制性不能被新模板的默认值取消。
